# Инструкции

Пошаговые инструкции по администрированию. В каждой объясняется, зачем нужен каждый шаг, а не только какую команду ввести. Адреса и имена в примерах условные: подставляйте свои.

| Инструкция | О чём |
|---|---|
| [WireGuard](wireguard/) | Свой VPN для удалённого доступа к закрытой сети: сервер, фильтр, проброс порта, устройства, разбор сбоев |

Каждая инструкция лежит в своей папке, в файле `README.md`.
